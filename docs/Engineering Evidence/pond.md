# Engineering Evidence：小水潭（add-pond）

## 變更摘要

在綠球正面左側加了一個程式產生的小水潭：
- 水面有深淺漸層、漣漪、岸邊水花；
- 岸邊有泥土、石頭、荷葉、小粉花和香蒲；
- 面板「小水潭」可以調整，可以拖曳；
- 小豬會繞過水潭，草叢不會長在水面上。

## 驗證佐證

- `tsc`、build 通過，瀏覽器實測沒有錯誤。

## 風險與後續追蹤

- 拖完水潭只更新遮罩（逐一檢查一千多個 instance 的方向），不重撒，整顆球的佈局不會變。
- 水面比地表高一點點，靠岸邊遮住邊緣。如果鏡頭貼地平視，可能看得出厚度。
