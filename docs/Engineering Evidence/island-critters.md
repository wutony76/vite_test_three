# Engineering Evidence：島上的小生物（add-island-critters）

## 變更摘要

- 新增蝴蝶（純色黃／紅／藍）、蜜蜂、蜻蜓、蚱蜢、小蜘蛛，各有飛行或地面行為，避開房子與食物。
- 每一隻輪流出現、停留、離開，依種類有不同出現頻率；面板可調同時最多數量、大小、速度、頻率、停留秒數。

## 驗證佐證

- tsc 通過、瀏覽器無錯誤；出現循環以 debug log 驗證（數量起伏）。
- 截圖：`assets/island-critters-closeup.png`、`assets/island-critters-scale.png`

## 風險與後續追蹤

- 避障依賴小豬每格更新的障礙清單；小豬關閉或還沒開始跑時，生物不會避障（開場動畫結束後才出現，影響不大）。
- 飛行高度固定在 0.025～0.1，會從比較矮的物件（食物）上方飛過。
