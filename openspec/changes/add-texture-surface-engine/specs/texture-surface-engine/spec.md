## ADDED Requirements

### Requirement: Textured surface materials
Plan materials with a `surface` field SHALL be built as image-textured materials (base color, ORM, normal) generated by the configured texture source, with UVs in meters chosen per profile or surface, while materials without `surface` keep the palette atlas.

#### Scenario: Crate uses wood textures
- **WHEN** `crate_pile` is built with `game_default`
- **THEN** its wood materials have base color, ORM and normal images, every textured mesh has a `UVMap`, and FLAT_RATIO is at most 30%

#### Scenario: Preview stays flat
- **WHEN** a plan is built with `preview`
- **THEN** no texture image is generated and no bake runs

### Requirement: glTF-compatible shader graphs
The Material Builder SHALL only use exportable nodes, SHALL set sRGB for base color and emission images and Non-Color for all data images, and Texture QA SHALL fail on any violation.

#### Scenario: Exported texture slots
- **WHEN** a textured asset is exported
- **THEN** the GLB materials reference `baseColorTexture`, `metallicRoughnessTexture`, `normalTexture` and, when baked, `occlusionTexture` with `texCoord` 1

### Requirement: Texture baking
When `bake` is `ao` or `full` and the asset has textured materials, the build SHALL create a non-overlapping `UVBake` layer, bake with Cycles into an image that is saved, reloaded and wired into the exported material, and SHALL restore render settings afterwards.

#### Scenario: AO bake
- **WHEN** `crate_pile` is built with `bake: ao`
- **THEN** an AO image exists with non-uniform values, UVBake overlap is below 0.5%, and the render engine is unchanged afterwards

### Requirement: Decals
Plan `decals` SHALL be built as separate alpha-masked quad objects parented to their target, offset along the face normal, sharing one decal atlas per asset.

#### Scenario: Shop sign decal
- **WHEN** `test01_shop` is built
- **THEN** each decal is its own object with `alphaMode` MASK in the GLB

### Requirement: Texture providers
Texture sources SHALL go through a provider interface (procedural, library, manual, ComfyUI) whose outputs are cached by request hash with provenance, so rebuilding never calls an external service.

#### Scenario: Missing provider output
- **WHEN** a material uses `provider:comfyui` but the cache is empty during a build
- **THEN** the build falls back to the procedural texture and reports a warning

### Requirement: Texture and visual QA
Texture QA SHALL check missing textures, UVs, stretch, overlap, padding, texel density, color space, node compatibility, missing files, GLB export, budgets and flat ratio; Visual QA SHALL add per-surface color, detail density and texture scale metrics as warnings.

#### Scenario: Quality report
- **WHEN** an asset is built
- **THEN** `report.texture` lists every check with a status and the manifest records texture bytes and GPU memory
