# Proposal

## 變更名稱

`add-tree-stump`：綠球上的樹墩，可放大、變寬且紋路不糊，可複製、可編輯（跟檸檬片一樣）

## 背景

使用者提供一張手繪風樹墩參考圖（方方的樹幹、切面年輪、右後方斷裂木刺、左下一截小樹枝），要求放在 world 的綠球上，
「需要可以變寬變大，但是紋路不可以變糊糊的」，並且可以像檸檬片一樣複製、編輯。

## 目標

- 綠球上新增樹墩，造型接近參考圖。
- 放大（縮放、大小）、單軸拉伸（寬、厚、高）時，紋路維持銳利、不被拉扁。
- 拖曳／點選選取、面板調整、複製、移除、印出佈局貼回，操作方式跟檸檬片一致。

## 範圍

- `src/world/objects/treeStump.ts`（程序化幾何＋程序化紋路 shader）、`treeStumpLayout.ts`（預設值與佈局）。
- `obj.ts`：生成／複製／移除、開場長出來、小豬障礙。
- `main.ts`：面板「樹墩」、拖曳與點選目標。

## 不在範圍

- 不做 Blender／GLB 版本（點陣貼圖放大會糊，與需求衝突）。
- 不加進「食物顯示」開關（樹墩不是食物）。
