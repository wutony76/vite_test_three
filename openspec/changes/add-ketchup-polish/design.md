# Design

## 1. 質感與顏色（`KETCHUP_SAUCE_DEFAULT`）

| 項目 | 舊值 | 新預設 |
|---|---|---|
| 顏色 | #e83055 | #c42a1f（帶橘的番茄紅） |
| 粗糙度 | 0.42 | 0.24 |
| 清漆／清漆粗糙度 | 0.2／0.55 | 0.7／0.2 |
| 自發光 | 0x5a1800 | #3a0c02 × 0.6 |
| 管子段數 | 25×8 | 200×24 |

- 段數加密後表面圓滑，清漆高光和亮邊才會是連續的弧線，不會一整片亮或一整片暗。
- 菲涅耳亮邊：亮度為 `rimColor × rimStrength × (1 − N·V)^rimPower`，加在自發光上。
- 接觸陰影：法線越朝向綠球中心，`diffuseColor` 越暗。綠球中心由 obj.ts 每幀傳入 `setBallCenter`。

## 2. 前景模糊（`src/world/foregroundBlur.ts`）

- 主場景畫完後，用 `copyFramebufferToTexture` 把畫面複製成貼圖，在半解析度下做兩輪橫、直高斯模糊。
- 疊回畫面的遮罩是 `1 − smoothstep(band × (1 − feather), band, uv.y)`：底部全糊，往上到 band 以上完全清晰。
- 為什麼依畫面高度，不只模糊番茄醬：醬會繞到綠球後面，單獨畫的話要處理被球擋住的部分（需要深度）。預設鏡頭下，畫面底部本來就是離鏡頭最近的醬，所以依高度模糊的效果幾乎一樣。
- 像素已經是 sRGB，全程不做色彩空間轉換。

## 3. 流動細節

- **流動高光**：沿管子方向移動的細亮帶，帶一點彎曲，只出現在正對鏡頭的那面。實測太密會像同心圓，所以頻率 20、指數 48。
- **小氣泡**：醬面切成 420×52 的格子，約 6% 的格子放一顆圓形亮點，跟著醬往前流。
- **漣漪**：
  - 每幀把小豬的世界座標交給 `ketchup.touch()`。換算到緞帶座標後，用同一個角度找管子中心線，算出小豬離醬面多遠。
  - 小於 `rippleDistance` 時，在醬面上離小豬最近的點放一圈漣漪，冷卻 0.45 秒。最多同時 4 圈。
  - 每圈存成 `vec4(中心, 開始時間)`。fragment 加一道往外擴散的亮環，vertex 讓醬面微微隆起，1.4 秒後消失。

## 4. 面板

- 「番茄醬質感」：顏色、暗部透色與強度、粗糙度、清漆光澤、清漆粗糙度、環境反射、邊緣亮光（強度、顏色、寬窄）、貼地陰影、流動高光與速度、小氣泡、小豬漣漪強度、多近起漣漪、印出設定。
- 「前景模糊（移軸）」：啟用、模糊範圍、過渡柔和度、模糊程度、最底部強度。
