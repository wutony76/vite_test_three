# Proposal

## 變更名稱

`add-ketchup-polish` — 番茄醬質感、顏色、前景模糊與流動細節

## 背景

使用者問「對番茄醬有什麼建議」，我提出四點，使用者要求先記錄目前狀態，再四點一起改：

1. **質感太平**：像紅色塑膠板，看不出濕亮的醬。原因：
   - 粗糙度 0.42、清漆只有 0.2。
   - 橘色自發光把暗部填平。
   - 管子只切 25×8 段。
2. **顏色太飽和**：`#e83055` 是全場最飽和的顏色，和粉彩風格衝突。
3. **前景太重**：預設鏡頭下，畫面底部約三分之一是清楚的大片紅色，搶走綠球的焦點。
4. **缺少流動細節**：看不太出「在流動」，和綠球的接觸也不明顯。

還原點：本機 annotated tag `before-ketchup-polish`（`973fcee`）。

## 目標

- 番茄醬改成帶橘的暖深紅，表面濕亮，邊緣有亮光，貼地側變暗。
- 畫面底部加移軸式前景模糊。
- 醬面加流動高光、小氣泡；小豬走到醬邊時起漣漪。
- 以上全部可以在面板調整，調好後印出設定貼回程式。

## 範圍

- `src/world/objects/ketchup.ts`：
  - 新增 `KetchupSauceSettings`、`applySauceSettings`、`touch`、`setBallCenter`。
  - shader 新增亮邊、接觸陰影、流動高光、氣泡、漣漪。
  - 管子加密成 200×24 段。
- `src/world/foregroundBlur.ts`（新）：移軸前景模糊。
- `src/world/objects/obj.ts`：每幀把小豬位置、綠球中心交給番茄醬。
- `src/world/main.ts`：新增面板「番茄醬質感」「前景模糊（移軸）」，主場景畫完後套用前景模糊。
