# Design

## 1. 分工

- **pig.ts**：只負責「怎麼走」。
  - `goTo` 指令：沿用去篝火的瞄準與避障。
  - 靠近目標時，探路忽略 `ignoreRoot`（例如房子本身），不然大門就在房子旁邊，會一直以為前面被擋住。
  - `allowNearTop` 暫時放寬「離頂端至少 12°」：龍兔的家在頂端 2°，大門口約在 14.7°，邊界附近。
  - 操偶模式：`setPuppet` 加 `setPuppetPose(位置, 鼻頭, 頭頂, 大小, 腳步)`。小豬不自己走，只更新腳步、雲、煙。
- **pigAdventure.ts**：負責「做什麼」，是一個狀態機，全部用 ground（綠球）座標。

## 2. 狀態機

| 階段 | 做法 | 時間 |
|---|---|---|
| idle | 冷卻 20～45 秒，到了擲骰子（60%） | — |
| toDoor | `pig.goTo(大門前)`；大門前 = 房子中心往大門方向走出「房子避障半徑 + 小豬半徑 + 0.5°」，站不下就再往外推 | 走路 |
| entering | 從大門前走向大門底部，後 45% 縮小到 0 | 1 秒 |
| inside | 藏起來 | 1 秒（可調） |
| exiting | 三樓洞口從 0 長回原本大小 | 0.35 秒 |
| walkPlatform | 走過木平台到滑道起點 | 平台長 ÷ 0.07 |
| sliding | 沿滑道曲線，u = k^1.6（先慢後快）；頭頂方向跟滑道斷面同一套座標 | 滑道長 ÷ 速度 0.3，0.8～4 秒 |
| plunge | 往前、往下沉 0.03（被水面擋住），縮到 0.7；落水時濺水花，擲骰子噴魚排（50%） | 0.3 秒 |
| hop | 拋物線跳到岸邊（水潭避障範圍外，優先朝落水那一側，站不下就左右轉找），再濺一點小水花 | 0.75 秒 |

跳上岸後呼叫 `resumeAt` 恢復遊走，回到 idle。中途溜滑梯或水潭被關掉時，小豬回到大門前。

## 3. 魚排

- 用既有的鮭魚排模型（`createSalmonSteak`）另外建立，大小 0.05（預設 0.16 是小豬身長的 3 倍，太大）。
- **落地點**：水潭避障範圍外 1.5～4.5°，要是小豬站得到的地方，試 24 次。
- **飛行**：拋物線最高 0.07，翻滾 2 圈，1 秒。落地用精確角度寫進設定再 `applySettings`；不用 `setNormal`，因為它會四捨五入到整數度，落地會跳一下。
- **撿**：落地時擲骰子（60%）。小豬有空、冒險沒在進行時，下 `goTo` 指令。走到後魚排 0.35 秒縮小消失，小豬停下 1.2 秒。
- **消失**：沒被追、落地超過 10 秒、而且不在畫面裡才收掉。在畫面裡的判斷：在鏡頭視錐內，而且在綠球朝向鏡頭的那一面。

## 4. 水花（pond.ts）

- 30 顆水珠和 3 圈波紋，第一次濺水時建立並掛在 ground 底下，之後重複使用。
- 水珠往上 0.3～0.62、往外 0.07～0.23，重力 1.6，落回水面就收起來。
- 波紋依序延遲 0.18 秒，往外擴散並淡出。
- 濺水點在滑道終點再往前 0.015：滑道終點貼近岸邊，直接在終點濺的話一半落在泥岸上。

## 5. 順手修正：InstancedMesh 的佔地範圍

- 小豬避障（`pig.ts`）和草叢避讓（`obj.ts`）都用「mesh 包圍盒投影到地表」算佔地。
- InstancedMesh 的 `geometry.boundingBox` 是單一顆的原始大小（水潭石頭是半徑 1 的 20 面體），沒套上每顆的縮放。
- 結果水潭被當成半徑 1 的大圓，**避障範圍 51.3°**。從加入水潭開始，小豬幾乎半顆球都走不過去，大門前也被判定站不下。
- 改成 InstancedMesh 用 `computeBoundingBox()`（所有 instance 合起來）。
- 其他障礙物沒有 InstancedMesh（篝火的火星不在 footprint 裡），草叢佈局不受影響。

## 6. 後續調整（使用者回饋）

### 小豬控制項第一層加「現在去溜滑梯」

放在「現在去看烤雞」旁邊，不用打開子資料夾。

### 「冒險已經在進行中」

- 使用者按按鈕時常看到這個訊息。原因有兩個：
  - 自動冒險很常觸發；
  - 走去大門走不到時，要等放棄才結束，放棄時間是依距離估的，遠的話要兩分多鐘。
- 改法：
  - 訊息寫出目前階段（例如「正在走去龍兔的家大門」「在屋裡」「正在溜滑梯」）。
  - 走去大門的放棄時間依距離估（直線秒數 ×3 ＋ 8），限制在 20～75 秒。原本先改成固定 40 秒，實測從綠球另一側要繞過好幾棟房子，40 秒走不到就放棄了。
  - 走去大門途中再按，會重新出發。

### 點擊馬上去溜滑梯

- 按鈕改成「馬上去」：不走去大門。
  - 原地輕輕一跳、0.35 秒縮小消失（`vanish` 階段）；
  - 在屋裡只待 0.3 秒；
  - 直接從三樓洞口出來滑下。
- 正在走去大門時按，也直接改成馬上去；已經進門或正在滑時不打斷，只顯示目前階段。
- 自動觸發的冒險照舊：走去大門、進門、在屋裡待 `insideSeconds`。

### 進大門不縮小

- `entering` 改成從大門前走到門口，再往門裡多走 0.035，全程大小不變，被房子擋住後才藏起來。
- 走路速度照小豬平常的 0.07／秒，最少 0.8 秒。

### 落水後 3 秒再慢慢爬出

原本是「沉一下、拋物線跳上岸」，改成三段：

| 階段 | 做法 | 時間 |
|---|---|---|
| `plunge` | 往前、往下沉 0.05，整隻沒入水面；大小不變 | 0.35 秒 |
| `underwater` | 在水裡不動（頭上的烏雲還在水面上） | 3 秒 |
| `climbOut` | 前 45%：從靠岸那一側的水下（水潭半徑 75% 處、水下 0.05）緩出浮到水面，泛起小波紋；後 55%：慢慢走上岸（腳步擺動），回到遊走 | 2.4 秒 |

### 面板「走去大門再溜（完整流程）」

在「溜滑梯冒險」子資料夾裡，按下去就走完整流程（走到大門、走進去、屋裡待一下、溜滑梯），方便看進門那一段。第一層的「現在去溜滑梯」則是馬上去。

### 溜滑梯時烏雲先消失，回到岸上再出現

- `pigCloud.ts` 新增 `setSuppressed(on)`。
  - 收起時記住原本的天氣，切到「沒有雲」（雲用原本的彈簧動畫縮掉），並立刻清掉半空中的雨滴和閃電，不然雲縮掉後還會看到幾滴雨落下、閃電閃一下。
  - 恢復時，隨機模式直接回到收起前的天氣，不重新抽籤，否則可能抽到「沒有雲」，看起來像雲沒回來。強制天氣模式照原本的強制值。
- `pigAdventure.ts`：
  - 開始進門（`entering`）或「馬上去」原地消失（`vanish`）時收起；
  - `finish()`（爬上岸、或中途放棄回到大門前）時恢復。

### 慢慢走上岸時整體傾斜

`climbOut` 時整個身體往後仰（鼻頭朝上），像在爬岸邊的斜坡。旋轉軸是「鼻頭 × 頭頂」，鼻頭往頭頂方向轉、頭頂往後倒。

| 時間 | 傾斜角度 |
|---|---|
| 從水下浮到水面（前 45%，1.08 秒） | 0° → 28°（sin 緩入） |
| 浮出水面後 0.5 秒 | 維持 28° |
| 之後 | 直接回到 0°（不慢慢轉回來），正常走上岸 |

使用者先後調整過兩次：
1. 原本是最後 30% 慢慢回正；
2. 第一次改成「走到岸上才直接回正」；
3. 最後改成「浮出水面 0.5 秒後就直接回正」。
