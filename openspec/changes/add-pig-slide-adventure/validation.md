# Validation

## 結果：通過

瀏覽器（headless Chromium）實測。headless 畫格率很低，以下是實際經過的秒數；動畫照 deltaTime 前進，在一般瀏覽器裡會快很多。

**整趟流程**（按「立刻去溜滑梯」）：

| 秒 | 階段 | 小豬大小 | 離球心 |
|---|---|---|---|
| 0.5 | toDoor | 0.3 | 0.996 |
| 24 | entering | 0.3 | 0.996 |
| 27 | inside | 0 | 1.01 |
| 29.5 | exiting | 0 → 0.3 | 1.01 |
| 31.5 | walkPlatform | 0.3 | 1.241（三樓） |
| 33 | sliding | 0.3 | 1.242 |
| 39 | plunge | 0.3 → 0.21 | 1.006 |
| 40.5 | hop | 0.21 → 0.3 | 0.976 |
| 44.5 | idle | 0.3 | 0.996 |

**撿魚排**（撿的機率設 1）：魚排落地後被標成追蹤中，小豬從 69° 外繞過障礙走到旁邊。魚排縮小消失，數量變成 0，小豬停下 1.2 秒。

**魚排消失**（撿的機率設 0、最少留 3 秒）：
- 水潭在背面（不在畫面內）時，約 3 秒後消失。
- 先把水潭轉到正對鏡頭，魚排到 5.6 秒仍然保留；轉走後立刻消失。

**水花**：一開始只看得到幾個小白點，而且一半落在泥岸上。放大水珠、波紋，並把濺水點往水裡移，之後清楚可見；魚排從水花裡翻滾飛出。

**其他**：

## 已知限制

- 出口高度 6.72 時，小豬從三樓洞口出來、走過平台那段會被菇傘邊緣擋住，從預設鏡頭看不到；滑下來那段看得到。
- 小豬比滑道寬，滑下時身體兩側會稍微超出槽壁。

**按鈕訊息**：
- 走去大門途中再按：重新出發，不顯示警告。

**完整流程**：
- 進門全程大小 0.3 不變，走進門裡才藏起來。
- 從 4 個較遠的起點都走得到大門：

## 烏雲收起、走上岸傾斜

在暴雨天氣下按「現在去溜滑梯」，每 0.3 秒記錄雲的大小、半空雨滴數、閃電，以及小豬頭頂方向和地表法線的夾角。

**烏雲**：

| 階段 | 雲大小 | 雨滴 | 閃電 |
|---|---|---|---|
| vanish → inside → exiting → walkPlatform → sliding → plunge → underwater → climbOut | 0 | 0 | 無 |
| 回到 idle | 1.02（暴雨） | 30 | — |

**傾斜**（climbOut 期間取樣）：0.9° → 8 → 12.4 → 15.9 → 19.6 → 24.5 → 26.2（設定最高 28°，落在兩次取樣之間）→ 22 → 15.4 → 9.4 → 4.2 → 0.6 → 上岸時 0°。

console 沒有錯誤。

**隨機天氣恢復**：去溜滑梯前是 thunder（打雷）；原地消失時雲從 0.19 縮到 0；爬上岸後恢復成 thunder（雲大小 1.02），沒有重新抽籤。打雷沒有雨滴，所以雨滴數是 0。

**浮出水面 0.5 秒後回正**（climbOut 期間每 0.3 秒取樣：傾斜角／離球心）：
- 0.7°／0.9515 → 8.7 → 12.4 → 16.5 → 19.6 → 22.7 → 24.8 → 26.4 → 27.5 → **28°／1.000（到水面）**；
- 維持 28° 約 0.5 秒；
- **直接變成 0°**，之後走上岸的每一筆都是 0°，回到 idle 時是 0°。

console 沒有錯誤。
