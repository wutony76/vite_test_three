# Proposal

## 變更名稱

`add-island-critters`：島上的小生物（蝴蝶、蜜蜂、蜻蜓、蚱蜢、小蜘蛛），讓綠球更活潑

## 背景

使用者要求在島上加生物讓場景更活潑；過程中補充：比例要跟小豬相符、再小三分之一、不要眼睛等細節、不要一直都在場上（要有出現頻率）、蝴蝶整隻純色（黃、紅、藍）。

## 範圍

- `src/world/objects/critters.ts`（新）：造型、行為、出現／離開循環。
- `pig.ts`：`isOpenGround`（用小豬這一格的障礙清單判斷空地，不重算）。
- `obj.ts`、`main.ts`：接線、面板「島上生物」。

## 不在範圍

- 不做 GLB 模型（程式拼的 low poly 幾何），不跟小豬互動。
