# Design

## 1. 造型

- 程式拼的 low poly 幾何、頂點顏色：身體 1 個網格；會拍的翅膀左右各 1 個網格（蝴蝶不透明雙面、蜜蜂／蜻蜓半透明）。
- 只留輪廓和顏色：不做眼睛、圓點等小細節。蝴蝶整隻純色：黃 `#FFD23C`、紅 `#F0473C`、藍 `#3C8CF0`。
- 身長（世界單位，綠球半徑 1、小豬約 0.057）：蝴蝶 0.015、蜜蜂 0.011、蜻蜓 0.023、蚱蜢 0.015、小蜘蛛 0.011（使用者要求從初版再小三分之一）。

## 2. 行為

- 綠球座標：法線 n＋切線 f＋高度；前進 = n、f 一起繞 (n × f) 轉（沿大圓走）。
- 蝴蝶慢慢亂飄、側傾；蜜蜂之字形飛一段停一下；蜻蜓衝刺 → 懸停；蚱蜢停一下跳一下（拋物線）；小蜘蛛爬一陣停一陣。
- 避障：前方多看兩個身長，問 `pig.isOpenGround`（障礙清單＋小豬活動範圍）；不是空地就大轉彎。

## 3. 出現頻率

- 每一隻輪流：出現 → 停留 10～25 秒 → 離開（會飛的往上飛走淡出、地上的縮小）→ 等一段時間再來。
- 等待時間依種類：蝴蝶 15～40 秒、蜜蜂 20～50、蚱蜢 25～60、蜻蜓／小蜘蛛 40～90（÷ 面板「出現頻率」）。
- 面板的數量是「同時最多幾隻」：蝴蝶 4、蜜蜂 3、蚱蜢 3、蜻蜓 2、小蜘蛛 2。
