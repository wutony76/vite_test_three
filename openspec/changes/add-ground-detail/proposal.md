# Proposal

## 變更名稱

`add-ground-detail` — 綠球表面細節（色彩斑塊、番茄醬陰影帶、草叢、泥土小徑、零星小道具）

## 背景

綠球是一顆 64×48 段的平滑球、單一 `MeshPhongMaterial`（#7ee8b8），上面只有地表小花。
近看是一整片平的綠，跟細節豐富的房子、浮空小星球相比顯得空。

## 目標

1. 表面色彩變化：大塊低頻深淺綠斑塊＋頂端偏黃綠、往番茄醬偏藍綠的漸層
2. 番茄醬交界陰影帶：綠球貼近番茄醬緞帶處加柔和暗帶（類 AO），讓緞帶「壓」在草地上
3. 會隨風擺動的草叢：數千叢 low-poly 小草（InstancedMesh），vertex shader 微風擺動
4. 泥土小徑：房子與篝火之間的彎曲小路（shader 依球面距離上色），房子被拖動會跟著更新
5. 零星小道具：小石頭、蘑菇、小樹叢（InstancedMesh），粉彩 low-poly

全部可從面板個別開關與調整。

## 範圍

- 包含：
  - 新增 `src/world/objects/groundDetail.ts`（綠球 shader 注入、草叢、道具、小徑網路、撒點）
  - `src/world/objects/obj.ts`：建立 groundDetail、提供房子／篝火／障礙物／緞帶資料、入場時機
  - `src/world/main.ts`：「綠球細節」面板
- 不包含：
  - 不做地形起伏（小豬、房子、拖曳都依賴完美球面半徑）
  - 小豬不改行為（不避開草叢與小道具、不刻意走小徑）
  - 不改地表小花

## 影響面

- 場景 / 物件：綠球材質（onBeforeCompile 注入）、ground 底下新增 4 個 InstancedMesh
- 核心模組：無
- 互動 / 輸入：新增 GUI 資料夾與「重新撒」按鈕
- 資源：無（全部程式產生）

## 風險與對策

- 技術風險：
  - 風險：綠球材質已被 styleGrade 包裝 onBeforeCompile
  - 對策：groundDetail 在 createObjs 內（styleGrade 掃描之前）先掛 hook，styleGrade 會串接在後
  - 風險：道具撒在房子、食物、小徑、番茄醬下
  - 對策：撒點時以「物件貼地投影半徑」「小徑球面距離」「緞帶上緣角度」做拒絕取樣；在房子長完後才撒
  - 風險：房子被拖動後道具不會跟著移
  - 對策：小徑每 0.5 秒依房子位置更新；草叢與道具提供「重新撒」按鈕
- 效能風險：
  - 風險：草叢數量多
  - 對策：一叢 3 片葉（6 個三角形）、單一 InstancedMesh、不投影；預設 2000 叢 ≈ 12k 三角形
  - 風險：小徑在 fragment shader 逐段算距離
  - 對策：段數上限 40，只有綠球一個物件跑

## 驗證方式

- 功能驗證：各項開關、數值即時生效；拖動房子後小徑跟著動；重新撒正常
- 視覺驗證：開／關對照截圖（全景＋近景）
- 效能驗證：draw call 只增加 4（草叢 + 3 種道具）
- 回歸驗證：小豬走動、番茄醬、styleGrade、浮空小星球、入場動畫

- [ ] 房子之間有彎曲小路
- [ ] 草叢會隨風擺、小道具散落，不壓在房子／食物／小徑／番茄醬上
- [ ] 入場時草叢與道具在房子長完後才長出來
