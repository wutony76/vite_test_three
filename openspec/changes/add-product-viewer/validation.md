## 問題與修正紀錄

- 問題：配色切換無效，三種配色都顯示藍色
  - 發現方式：三種配色截圖比對
  - 原因：模型內配色名稱為小寫（midnight），官方 README 寫成大寫（Midnight）
  - 修正方式：名稱比對改為不分大小寫，找不到時 console.warn 列出可用名稱
  - 是否已重新驗證：是
- 問題：色票顏色與實際不符（原本依名稱猜測）
  - 修正方式：依截圖取色，更新色票與顯示名稱；預設改為模型預設的 midnight
- 問題：`PCFSoftShadowMap has been removed` 警告
  - 修正方式：改用 `PCFShadowMap` + `shadow.radius`
- 問題：重設視角後相機與預設位置仍差 0.01
  - 原因：拖曳殘留的阻尼慣性在動畫結束後繼續轉動相機
  - 修正方式：動畫期間關閉阻尼與自動旋轉，結束後恢復
  - 是否已重新驗證：是（距離 0）
