## 問題與修正紀錄

- 整體過曝、霓虹顏色被洗白 → toneMappingExposure 0.78、燈條 / 工作燈 / 串燈 / 燈條 Shader 亮度下調
- 背景大樓太近太亮 → 移到 x ±15 以外、窗光強度 0.7 → 0.28
- 前景行人擋住畫面 → 行走範圍不超過 z 5
- 收攤後熱氣仍是白色亮柱（Sprite 不受光照）→ 熱氣亮度跟著攤位平均亮度
- 未通電燈泡太亮 → 0.06 → 0.02
- Sass `unquote()` 棄用警告 → 改用插值 `#{$hex}`
- 使用者回饋「整體環境光偏暗」→ 新增基本光：HemisphereLight（夜空藍紫 / 地面暖色）+ 補光 DirectionalLight，控制台新增「環境光」滑桿，各情境各自設定（開市 1、派對 0.7、微醺 0.8、收攤 0.6）；收攤時仍看得到攤位輪廓
  - 效能：有 / 無基本光 33 / 35 FPS（測試當下系統負載 3.4，影響約 2 FPS）
- 使用者回饋「地板改水泥地」→ 程式產生水泥貼圖（斑駁、污漬、每 4 公尺分割縫、細裂縫）+ 凹凸貼圖
- 使用者回饋「地板不要反光」→ 移除 Reflector 與水窪遮罩，水泥 roughness 1（完全霧面）；同負載下 FPS 33 → 39（不再為倒影多畫一次場景）
