# Design

## 1. 寶箱模型（`chest.py`）

| 元件 | kind | profile | 做法 |
|---|---|---|---|
| body | chest_body | building_shell | 一條 loft，四個長方形環依序是：外底 → 外頂 → 內頂（箱口邊）→ 內底（墊高到 0.13）。中空但是 1 個封閉島；內牆和內底用深色 |
| bands | chest_bands | trim | 正面、背面各兩條金色直條，加上箱口四條金邊，共 8 個小方塊。左右兩條往內縮 1 mm，避免角落重複頂點 |
| lid | chest_lid | building_shell | 沿 X 軸 loft 半橢圓切面（拱頂加平底），包邊位置的切面放大 1.06 倍成為金色拱條，再繞背面上緣的鉸鍊轉 −110° |
| lock | chest_lock | decoration | 金色鎖板，加一個往前凸的深色鑰匙孔 |

- 拱條連底邊也往外移 4 mm。平底是一條直線，若拱條和箱蓋的底邊都在 z=0，兩圈之間的台階面會是面積 0 的退化面。第一版就有 4 個退化面。
- 箱蓋打開後佔的空間（bounds）是先用數值算出來，再寫進 plan。

## 2. 網頁端（`treasureChest.ts`）

- **座標**：寶箱模型座標是 glTF 的 +Y 朝上、+Z 為正面（Blender 的 −Y 正面匯出後變成 +Z）。
- **漢堡擺放**：`BURGER_PILE` 列出 13 個漢堡的位置、歪斜、自轉，順序是箱底 6 個 → 小山 3 個 → 山頂 1 個 → 掉出來 3 個。漢堡數量變少時從後面拿掉，所以先少的是掉在外面的，箱子裡永遠是滿的。
- **漢堡置中**：`burger.glb` 的根節點有 `translation [6.5, 0, 0]`，原點不在漢堡中心。實測每個漢堡自轉時，偏移量會轉到不同方向，漢堡全散在箱外。所以載入時先把底部中心移到原點。
- **漢堡的兩層結構**：外層設位置和歪斜，內層設自轉，歪斜方向才不會跟著自轉亂掉。
- **閃光**：
  - 箱口上方一團加法混合的光暈，透明度隨時間起伏。
  - 6 顆四角星，亮度是 max(0, sin)³。每閃完一次就換到漢堡堆上的另一個隨機位置，看起來是整堆漢堡在發亮。
- **接線**：
  - 加進 `getPigObstacleRoots`，小豬和草叢會避開寶箱。
  - 開場動畫在房子長完之後冒出來。
  - 加進拖曳目標，也加進預載清單（`treasure_chest.glb`、`burger.glb`）。
- **預設擺放**：使用者在面板調好的值，離頂端 41°、方位 149°、自身旋轉 −141°、大小 0.08。
