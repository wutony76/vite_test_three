# Proposal

## 變更名稱

`edit-grilled-corn-panel`：開放新增烤玉米，選取與編輯改成跟檸檬片一樣

## 背景

使用者要求：
- 「我需要增加烤玉米」
- 「烤玉米的選取跟編輯幫我用檸檬片的方式」

原本烤玉米的編輯面板已經寫好，但被 `CORN_SCENE_EDIT = false` 關閉：沒有面板，場景上也不能點選、拖曳。

## 目標

- 烤玉米跟檸檬片一樣一直可以選取、拖曳。面板「烤玉米」可以複製、移除、印出全部佈局。
- 選取方式和面板結構跟檸檬片一致：
  - 選中的那根整根發光；
  - 標題顯示選中的是哪一根；
  - 滑桿都在同一層；
  - 移除後自動選下一根。

## 範圍

- `src/world/main.ts`：改寫烤玉米面板，移除 `CORN_SCENE_EDIT`。
- `src/world/objects/obj.ts`：`addGrilledCorn` 從選中的玉米複製時，方位錯開 12°。
