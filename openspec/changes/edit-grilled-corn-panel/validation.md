# Validation

## 結果：通過

瀏覽器實測：真的用滑鼠在場景上點選，並用面板按鈕操作。

| 動作 | 面板標題 | 發光的玉米 |
|---|---|---|
| 開頁 | 烤玉米 · grilled_corn_1 | 第 1 根 |
| 點第 1 根 | grilled_corn_1 | 第 1 根 |
| 點第 2 根 | grilled_corn_2 | 只有第 2 根 |
| 點第 4 根 | grilled_corn_4 | 只有第 4 根 |
| 複製玉米 | grilled_corn_6（5 → 6 根，方位從 −175° 錯開到 −163°） | 只有第 6 根 |
| 移除選中玉米 | grilled_corn_5（6 → 5 根） | 只有第 5 根 |

- 第 3、5 根在預設視角被房子擋住，點下去會選到房子，這是正常的。
- 外觀子資料夾 0 個；按鈕只有「複製玉米／移除選中玉米／印出全部佈局 (console)」。
- 修正過程抓到並修掉的問題：
  - 換選後前一根還在發光：發光沒有還原。
  - 剛開頁面時選中的那根不發光：模型載入慢，原本只補 6 秒，改成 60 秒。
- console 沒有錯誤；`tsc`、`npm run build` 通過。
