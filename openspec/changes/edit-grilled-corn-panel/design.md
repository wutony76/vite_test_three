# Design

## 對照檸檬片

| 項目 | 原本的烤玉米 | 改成（同檸檬片） |
|---|---|---|
| 開關 | `CORN_SCENE_EDIT = false`，面板、點選、拖曳都關閉 | 移除開關，一直可以編輯 |
| 選中標示 | 只把名稱含 kernel／body 的材質調亮，幾乎看不出來 | 整根 `emissive = color`、強度 0.35 |
| 面板標題 | 先寫標題再清除，清除時又把標題改回「烤玉米」 | 先清除再寫「烤玉米 · 名稱」 |
| 外觀滑桿 | 放在「外觀（即時）」子資料夾；清除只刪滑桿不刪子資料夾，每換一根就多疊一個 | 全部放同一層 |
| 按鈕 | 新增玉米／移除選中玉米／印出全部設定／重載頁面 | 複製玉米／移除選中玉米／印出全部佈局 (console) |
| 移除後 | 不選任何一根 | 自動選最後一根 |

## 另外修的問題

- **複製時疊在一起**：從選中的玉米複製時直接用它的方位，新玉米和原本那根完全重疊、看起來像沒新增。改成 `wrapDegrees(方位 + 12)`，跟香菇一樣。
- **發光還原**：玉米的 `applyVisuals` 只重設玉米粒和本體的材質，葉子等其他材質的發光不會被清掉，換選後前一根還在發光。
  - 改成發光前用 `WeakMap` 記下每個材質原本的 emissive 顏色和強度。
  - 取消選取時先還原，再 `applyVisuals`。
- **模型還沒載入就選中**：剛開頁面或剛複製時模型還沒掛上，沒有 mesh 可以發光；載入完成時玉米會重新套外觀，也會把發光蓋掉。
  - 改成選中後每 0.25 秒檢查一次：有 mesh 但沒在發光就補上，最多等 60 秒。

## 擺好後關閉編輯

- 使用者用面板擺好 6 根後，把印出的佈局寫回 `grilledCornLayout.ts` 的 `GRILLED_CORN_PLACEMENTS`：
  - 新增第 6 根：離頂端 8°、方位 −57°、縮放 1.15；
  - 第 5 根熱氣 1.8。
- `CORN_SCENE_EDIT = false`：
  - 面板「烤玉米」隱藏（`hide()`）；
  - 不加入拖曳目標，點選、拖曳都不會選取；
  - 開頁時不預先選第一根（選中會整根發光）。
- 面板程式保留。要再調整時改成 `true`，面板、點選、拖曳都會回來。
