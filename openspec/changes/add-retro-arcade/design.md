# Design

## 1. 零件（`retro_arcade.py`）

- **機身**：側面輪廓 `CABINET_PROFILE`（背面直、頂上招牌箱突出、斜螢幕內凹、操作台下方、正面、踢腳板）沿 x 擠出，1 個島。
- **共用輪廓**：側板用同一條輪廓的下半段；螢幕框用 `SCREEN_TOP`／`SCREEN_BOTTOM` 定出的斜面座標系（`_on_screen`），貼在斜螢幕上。
- **左側 kitbash 全部朝 −x**：相機（盒＋沿 x 的鏡頭旋轉體＋提把管）、喇叭（外圈和網同一個旋轉體＋5 個孔）、旋鈕盒、糖果按鈕盒（params.colors）、通風箱。
- **其他**：操作台（檯面、橘色前緣、黑桿紅球搖桿各一個旋轉體、圓鈕、投幣口）、投幣門、頂上招牌箱、紅盒、腳墊。

## 2. 網頁（`retroArcade.ts`）

- 擺法同 Happy Fat：離頂端角度、方位、自轉、大小、下沉。另外有 `screenGlow`，調螢幕發光（bezel 節點上的自發光材質）。
- **預設位置**：在頁面上掃描遊樂中心附近 6～16° 內、畫面上在它左邊、半徑 2.5° 內沒有其他東西的空地，取最近的：離頂端 28°、方位 22°。
- **預設自轉**：125°，正面朝鏡頭為主、左側 kitbash 也看得到。評分是「正面·鏡頭 × 0.85 ＋ 左側·鏡頭 × 0.5」。
- **小豬**：會繞過街機（加入小豬障礙清單）。
- **草叢**：用遮罩避開，跟水潭一樣不放進撒點障礙，避免整顆球的草叢重排；拖曳結束時呼叫 `groundDetail.refreshMasks()`。
