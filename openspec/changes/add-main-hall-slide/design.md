# Design

## 1. 起點：射線找三樓外牆

香菇屋屋身是葫蘆形，每層半徑都不同，不能寫死一個半徑。

做法：
- 在屋身座標裡，從三樓高度（`startHeight` 預設 5.75；菇傘從 6.85 開始），朝水潭方向的外面往中心打射線，打到的就是外牆。
- 屋身材質是單面，所以從外面往裡打；從裡面往外打不到。
- 出口方向可以用 `exitAngleDegrees` 繞房子轉，用來避開香菇串和窗戶。
- 長度單位是「香菇屋模型的 1 單位」：屋身 worldScale ÷ ground worldScale。房子縮放改了，滑梯粗細也會跟著變。

## 2. 出口

- **拱門**：ShapeGeometry，一個上方是半圓的拱形，深色，貼在外牆上、面朝外。
- **平台**：Cylinder，跟房子的「上」方向對齊。
- **欄杆**：沿平台外緣半圈的柱子，加 Tube 扶手；正前方留一個開口接滑道。

## 3. 滑道曲線

- **水平**：在球面上從起點 slerp 到終點，再沿 `startDir × endDir` 方向往側邊彎 `sin(πt) × curve × 距離`。
- **高度**：`0.65·t + 0.35·smoothstep(t)`。
  - 一開始只用 smootherstep，結果中段陡到接近垂直，因為水潭離房子很近（實測過）。
  - 改成以等速下降為主，只保留一點頭尾的緩衝。
- **終點**：從水潭中心往房子方向退到 `size × (1 − endInset)`，離地 0.006，剛好在水面上方。

## 4. 滑道幾何

- U 形斷面：內弧加外弧（厚度 0.1 單位）組成封閉輪廓，沿曲線掃 180 段。
- 每段的「上」是球心往外的方向；側邊 = 切線 × 上。
- 支柱：在 t = 0.22、0.42、0.62 處，如果離地超過 0.6 單位，就往球心方向立一根到地面。

## 5. 更新與效能

- 每 0.25 秒比對一次 key（水潭方向和大小、屋身矩陣、形狀設定），有變才重建；顏色只改材質。
- 房子開場長大期間不算：屋身一直在變，算了也白算。
- **開場動畫**：用 `setDrawRange` 只畫滑道前一段三角形，看起來像從三樓伸出去；平台、門、支柱在滑道開始伸出時一起出現。
- **點擊**：全部 mesh 的 `raycast` 設成空函式，不會擋住點擊或拖曳。
- **水潭關掉時**：溜滑梯隱藏，因為沒有終點。

## 6. 欄杆不穿過滑道（使用者回饋）

- **問題**：原本開口寫死為「正前方 ±0.45 rad 不放柱子」。滑道外緣半寬約 0.55 單位，缺口旁 45° 那根柱子的側向距離只有 0.55，剛好插在滑道邊緣。
- **改法**：
  - 依滑道寬度計算：`chuteHalfOuter = (width/2 + 0.1) × unit`。
  - 柱子的側向距離 `|cos a| × railRadius` 小於 `chuteHalfOuter + 0.17 × unit` 就不放；柱子改成每 15° 一根。
  - 平台半徑 `max(0.85, chuteHalfOuter + 0.45)` 單位，滑道變寬時平台跟著變大，兩側還有地方放欄杆。
- **顏色**：滑道預設 `#FF674D`。

## 7. 支柱不穿刺（使用者回饋）

- **問題**：原本從槽底中心沿球心方向立一根柱子。滑道是斜的、柱子是垂直的，柱頂圓面會有一半（約 `半徑 × tan(坡度)`）冒出槽底，刺進滑道；滑道越陡越明顯。
- **改法**：每一站改成「兩側立柱＋底下橫桿」。
  - **立柱**：在斷面座標的側邊 `±(w + 厚度 + 柱半徑 + 0.06)`，從槽壁一半高的位置沿球心方向立到地面。側邊向量垂直於球心方向，所以整根柱子的側向距離都不變，不會碰到滑道。
  - **橫桿**：接在兩根立柱上，沿立柱往下 `drop = (0.5·depth + 厚度 + 桿半徑 + 0.06 + 0.08) / cos(坡度)`，保證落在槽底外殼的下方；`cos` 最小取 0.2，太低（超過柱高）就不放。

## 8. 移除支柱、頂端改成可延伸平台（使用者回饋）

- **支柱**：整段移除（取代第 7 節）。
- **平台**：原本的圓形平台和半圈欄杆，改成從外牆往外延伸的長方形平台。
  - 長度是 `platformLength`，模型單位，0.3～4，預設 1.2。
  - 往牆裡多埋 0.3，避免葫蘆形外牆和平台之間露縫。
  - 平台半寬 = 滑道外緣半寬 + 0.38。
- **欄杆**：兩側各一排，每 0.35 單位一根柱子，扶手沿柱頂折線連接；末端不封口，留給滑道。
  - 菇傘邊緣往下垂到屋身 y≈6.18，比欄杆頂（5.75 + 0.55）低，平台伸到菇傘底下會頂進去。
  - 所以每根柱子建立時沿屋身朝上方向打射線找菇傘底面，高度取 `clamp(到菇傘距離 − 0.15, 0.18, 0.55)`。
- **滑道起點**：從平台末端外 0.02 開始，先沿平台方向直直伸出 `滑道外緣半寬 + 0.3` 的導引段，再轉往水潭。
  - 少了導引段，平台很長時滑道一開始就斜向水潭，起點那幾圈會壓回平台（實測有 20～38 個頂點在平台裡）。
- **面板**：新增「頂端平台長度」；顏色項目改名為「平台欄杆顏色」。

## 9. 滑道平台（平段）和頂端木平台分開控制（使用者回饋）

- 使用者說明：滑道的平台和頂端平台是兩個物件。
- **頂端木平台**：`platformLength`，從外牆伸出的木平台，有欄杆。面板名稱改成「頂端平台長度（木平台）」。
- **滑道平台**：`chuteFlatLength`，模型單位，0.5～5，預設 1。
  - 是滑道本身最上面那段水平的 U 形槽，接在木平台後面，取代原本固定長度的導引段。
  - 長度至少「滑道外緣半寬 + 0.3」，避免滑道一轉向就壓回木平台。
- 平段每 0.25 單位放一個控制點。只放頭尾兩點的話，CatmullRom 在長平段上會彎起來。

## 10. 滑道平台最短 0.1（使用者回饋）

原本平段最短卡在「滑道外緣半寬 + 0.3」（約 0.5～0.9）。目的是避免滑道一轉向就壓回木平台。要讓平段可以短到 0.1，路徑改成三段：

1. **平段**（滑道平台）：`chuteFlatLength`，最短 0.1。
2. **直線下坡段**：沿平台方向直直往外 `滑道外緣半寬 + 0.4`，同時開始下坡。
   - 寬滑道急轉彎時，內側槽緣會往後掃。實測平段 0.1、寬 1.6、側彎 ±0.5 或出口 −90° 時，槽緣往後掃回木平台和欄杆：壓進平台 14～32 點，欄杆距離是負的。
   - 先直線滑出半寬以上，等內側槽緣也離開平台後才開始轉。
3. **轉彎段**：二次貝茲曲線，控制點在轉彎起點正前方，起點方向等於平台方向。
   - 側彎改用 `sin²(πt)`：頭尾的值和斜率都是 0，不會在轉彎起點突然偏向，也不改變終點位置。

**其他調整**
- **高度**：改成依實際水平弧長分配（不用參數 t），直線段和轉彎段的坡度才會連續。曲線是前 25% 二次緩升，之後等速下降。起點坡度 0，避免傾斜的斷面一開始就往後倒；最陡處只比等速陡 14%。
- **出口高度**：滑桿上限 6.8 → 6.0。菇傘邊緣最低在 y≈6.18，平台再高就會伸進菇傘（實測 6.5 時有 53 點）。

## 11. 預設值、出口更高、平台寬度、平台洞、側面曲線（使用者回饋）

**預設值**（使用者在面板上調好的值）：

| 項目 | 值 |
|---|---|
| 出口高度 | 6 |
| 出口繞房子 | 22° |
| 頂端平台長度 | 0.6 |
| 滑道平台長度 | 0.3 |
| 側彎 | 0.09 |
| 寬度 | 0.9 |
| 終點伸進水潭 | 0.15 |
| 滑道顏色 | `#ff674d` |
| 欄杆顏色 | `#f08a4b` |

新增項目的預設值：平台寬 1.86、洞 0.9 × 0.95、側面弧度 0、側面平滑 0.5。

**菇傘量測**（`capClearanceAbove`／`capRoom`）：
- 用雙面材質的代理 mesh 打射線。菇傘材質是單面，點在菇傘實心裡往上打不到表面。
- 「在實心裡」的判斷是上、下都穿過奇數次表面。只看往上會把傘殼底下的空腔（貼近屋身處）誤判成在裡面。
- `capRoom` 在中心和前後左右各偏 0.1 量五次取最小值，因為欄杆有粗細、傘緣很陡。

**出口高度**：
- 滑桿上限改成 7.2。實際高度由 `capSlack` 逐點量平台頂面（需 0.05）、滑道平段和起滑段槽壁（需槽深 + 0.08），不夠就往下修，每次最多 0.3，最多 16 次，並把值寫回設定、面板放開時更新顯示。
- 欄杆不列入高度限制：菇傘底下放不下最矮欄杆（0.18）的位置，那根柱子省略、扶手斷開。
- 實測最高可到：平台長 0.6 為 6.75、長 2 為 6.9、長 4 為 7.05。

**平台寬度** `platformWidth`：
- 最窄 = 滑道外緣 + 0.25，太窄會自動加寬並寫回。
- 平台往牆裡埋 `r − √(r² − 半寬²) + 0.2`（r 是外牆半徑），比房子寬時埋到中心軸。欄杆從各自那一側的牆面開始。
- 香菇串避讓：在平台前後與高度範圍內、且不跨中線的香菇串，平台半寬收到它前面 0.08（實測寬 5 時原本撞到 hanger_1，現在會收到約 2.6）。

**平台洞**（拱門）`doorWidth` / `doorHeight`：
- 12 × 12 網格，上半是半圓（洞比寬還矮時是半橢圓）。
- 每個頂點依沿牆弧長換算成角度，用射線貼到外牆、往外 0.03，寬的洞也不會浮在弧形牆外。
- 洞高上限：在牆外 0.3／0.5／0.8 處量菇傘底面，取最低值再減 0.06。
  - 不量貼牆處：傘底中間是空的。
  - 不量洞頂本身：伸進傘殼底下的洞頂不算在實心裡。

**側面曲線**：
- 平滑 `heightSmooth` 0～1：兩端緩衝長度 `ease = 0.05 + 0.4 × smooth`，二次緩入、等速、二次緩出，起點坡度一定是 0。
- 弧度 `heightArc` −1～1：`e + 0.3·arc·sin(πe)`。斜率倍率最小 1 − 0.3π ≈ 0.06 > 0，一路往下；頭尾斜率維持 0。

**已知限制**：出口繞到 −90° 附近時，平台和洞會蓋到三樓窗戶（window_top）；預設 22° 沒有這個問題。

## 12. 頂端平台寬度最小 0.1（使用者回饋）

- 取消「最窄 = 滑道外緣 + 0.25」的自動加寬。滑桿改成 0.1～5，數值照設定保留，不再被改寫。
- 平台半寬 ≥「滑道外緣 + 0.25」才放兩側欄杆；比這個窄就不放欄杆，變成一塊窄木板，避免欄杆插進滑道。
  - 預設滑道寬 0.9 時，門檻是平台寬 1.6。
- 滑道比平台寬也沒關係：滑道從平台末端外 0.02 才開始，先直線滑出再轉彎，不會壓到平台。
- 香菇串避讓收窄的下限也改成半寬 0.05。
