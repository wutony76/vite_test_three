# Proposal

## 變更名稱

`add-main-hall-slide`：從龍兔的家（mainHall）三樓到水潭邊的溜滑梯

## 背景

使用者先把水潭移到龍兔的家附近（離頂端 16°、方位 171°），再要求「在 mainHall 的三樓到水潭邊增加一個溜滑梯」。

## 目標

- 三樓外牆有一個出口：拱門、小平台和半圈欄杆。
- 黃色 U 形滑道從平台往外弧出，平順地滑進水潭岸邊；底下有支柱撐到地面。
- 水潭被拖動時，滑道自動重新接到新位置。
- 開場時，滑道在房子長好之後從三樓一路伸到水潭。
- 面板「溜滑梯（龍兔的家 → 水潭）」可以調整出口高度、出口方向、側彎、寬度、終點伸進水潭的程度和顏色。

## 範圍

- 新增 `src/world/objects/mainHallSlide.ts`（程式產生）。
- `obj.ts`：取得香菇屋屋身 mesh，建立溜滑梯，接上更新、開場動畫和對外介面。
- `main.ts`：面板。

## 不做

- 不走 Blender 建模：兩端都會動（水潭可以拖曳），滑道曲線要在執行時算。
- 不讓小豬去溜：只做場景物件。
