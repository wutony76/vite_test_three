# Design

## 1. 外觀

- 後面高機台：深紫機身（頂上招牌箱突出、大螢幕往後微傾、下方小操作台），兩側黑色喇叭塔各兩顆喇叭。
- 頂上招牌 decal：洋紅「電波」＋黃色「STEP!」；螢幕 decal：四欄彩色箭頭往上捲的譜面。
- 前面舞台：深色平台＋兩塊金屬踏板（3×3 格），8 個發光箭頭（上黃、下青、左洋紅、右萊姆綠），前緣 U 形金屬扶手＋中間直柱；舞台上緣、機身正面兩側青色燈管。

## 2. 零件（`dance_machine.py`）

- 機身：側面輪廓沿 x 擠出，1 個島。箭頭：俯看輪廓擠出，1 個箭頭 1 個島。
- `_prism_out`：`prism` 的 axes 是奇數次軸互換（如 `"xzy"`）時輪廓要反向，面才朝外；測試用有號體積檢查每個零件都朝外。

## 3. 網頁（`danceMachine.ts`）

- 擺法、選取、複製同復古街機（`DANCE_MACHINE_PLACEMENTS`，面板印出後貼回）。
- 預設位置在頁面上試出來：離頂端 35°、方位 36°、自轉 145°（螢幕與舞台朝鏡頭，不壓到旁邊的瑪芬）。
- `_glow` decal 當自發光；箭頭跟著 BPM 閃：匯出時材質合併成 atlas，8 個箭頭共用一個發光材質，所以是「全部一起閃」，用網格名稱 `dance_machine_arrows` 找到它；只調發光幾乎看不出來，底色也一起調暗調亮。
- 小豬會繞過；腳下草叢用遮罩藏起來（不放進撒點障礙，避免整顆球草叢重排）。
