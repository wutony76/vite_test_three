# Design

## 1. 外觀

- 下半顆：淺金黃麵包，底圓、側面外鼓，切口是米白麵包心。
- 奶油：厚奶油片（圓角、上下緣倒角），略斜放，往前、左、右突出麵包外。
- 上半顆：菠蘿酥皮圓頂，約 22 塊隆起的龜裂格；格線往內凹並換成深橘褐色（`crust_groove`），遠看才看得出格子。
- 木牌：兩片歪斜木板（輪廓不規則、各自轉一點角度），兩根木樁插進酥皮、上端露出木板；字是 decal（奶油色粗圓字＋深咖啡外框＋陰影）。
- 木牌上緣 4 叢青苔、2 朵小紅菇。

## 2. 零件（`pineapple_bun.py`）

- 麵包上下兩半都是 lathe 旋轉體（organic，1 個封閉島）；龜裂格用 voronoi（上半球的費波那契種子）只移動頂點、不加面，所以仍是 1 個島。溝的面換材質不增加島數。
- 奶油：圓角矩形 4 層 loft。木板：不規則輪廓用 `_prism_out` 擠出（奇數次軸互換時輪廓反向，面才朝外）。
- 每個零件最後用 `_fit()` 縮放到剛好填滿 bounds（Geometry QA 會檢查超出、不足）。
- 貼圖：酥皮用 cylinder UV（planar 在圓頂上每個面各自投影，看起來像拼布）；上半顆用 painted、下半顆用 crust（焦斑色改成接近底色，避免黑斑）。木牌降成 prop tier，GPU 貼圖才在 10 MB 預算內。

## 3. 網頁（`pineappleBun.ts`）

- 定位在番茄醬圈圈上，用固定角度（不看畫面比例）：
  - 鏡頭是繞著圈圈中心軸轉的，所以「圈圈上離鏡頭最近的點」永遠在畫面正下方。
  - 從那一點沿著圈圈往畫面左邊繞 `ringAngleDegrees`（預設 115°；> 90° 是醬圈後段，在綠球後面）。哪個繞行方向是畫面左邊，用往兩邊各繞一點、投影後比左右決定。
  - 鏡頭怎麼轉、視窗寬窄怎麼變，麵包在醬圈上的位置都不變（使用者要求：視窗寬度改變時不改變位置）。
  - 曾經試過「沿著醬找畫面 x = -0.7 的點」：位置會跟著視窗寬度變（1000 寬 132°、1800 寬 100°），已改掉。
- 朝向 = 鏡頭的旋轉 × 自己的轉向／前傾／搖晃，木牌一直面向鏡頭。
- 起伏：沿畫面的「上」浮動，兩個頻率疊加（不會像機器一樣規律）。
- 不投影子：鏡頭轉時影子會在綠球上亂跑。
- 在 `controls.update()` 之後更新，用的是這一幀轉完的鏡頭。

## 4. 跟番茄醬的互動（`ketchup.ts`）

- `ketchupRing.setFloatingObstacle(center, radius, dentDepth)`：main.ts 每幀把麵包底部中心、半徑交給番茄醬。
- 醬面凹洞：醬的 vertex shader 在麵包附近沿法線往內壓 `dentDepth`（中心全壓、往外平滑回到原本醬面）。醬一團一團流、表面蠕動，少了凹洞會一下一下從麵包底部穿出來。
- 食物、鯊魚繞過：把麵包換成「圈圈上的 progress＋截面的 climb」。經過時把 climb 暫時往自己本來偏的那一側挪開（不改 rider.climb），沿圈圈方向用 smoothstep 漸進、離開後自然回到原路線；那一側會繞到醬背面（|climb| > 1.3）就改走另一側。
- 麵包起伏時另外慢慢左右轉（`turnDegrees`，以 `yawDegrees` 為中心）。

## 5. 開場時機

- 番茄醬開場是沿著圈圈長出來（`setWrap` 0 → 1）。`ketchupRing.getWrap()` 回報目前長到哪裡，main.ts 每幀呼叫 `pineappleBun.setSauceReady(wrap >= 0.999)`。
- 醬繞滿之後麵包才出現：1.1 秒內從醬裡往上冒、easeOutBack 彈一下長大。開場重播（wrap 回到 0）時會再藏起來，等醬長滿再浮上來。

## 6. 貼著醬面（不浮在空中）

- 醬面會動：vertex shader 的鼓包（±0.03，沿醬圈往前流）＋蠕動（±0.012），還有凹洞；整條醬也繞自己的軸自轉。
- `ketchupRing.getSurfacePoint(angle, radialOffset, up)`：扣掉自轉換成醬自己的角度 → curve 上的點 → 沿著截面上的 up 方向走「管子半徑＋sauceSwell」（跟 shader 同一條公式），回傳醬面的世界座標。
- 麵包底部放在醬面上，再往下 `sauceDent`（凹洞）＋ `lift`（相對醬面，預設 -0.03 = 稍微沉進醬裡）。起伏 ±0.026 時底部也不會離開醬面。
- 舊作法是「管子中心＋固定高度」，醬面在鼓包之間往下凹（加上起伏、凹洞）時底部最多離開醬面約 0.06，看起來浮在空中。
