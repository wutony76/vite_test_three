## 問題與修正紀錄

- 跳躍無效、揚塵不出現
  - 原因：cannon-es 的 `updateWheelTransform()` 內部呼叫 `updateWheelTransformWorld()` 會把 `isInContact` 重設為 false，同步輪子模型後再讀就永遠是 false
  - 修正：在同步輪子前先記下每輪著地狀態與後輪著地點
- 車子直接穿過跳台、邊界牆、樹幹
  - 發現方式：位置追蹤顯示車子在跳台中心高度不變；射線檢測只打到地面；跳台包圍盒仍在原點
  - 原因：建立剛體後直接設定 position 不會更新包圍盒（AABB），靜態與睡眠物體每步不重算 → broadphase 找不到
  - 修正：加入世界前 `body.aabbNeedsUpdate = true`（`addBody` 小工具），已重新驗證跳台、邊界
- 區域名稱文字方向相反 → 旋轉加 π，從島中心開過去時文字為正
- 手機標題卡擠到右上按鈕 → 小螢幕縮小標題與按鈕
- 使用者回饋「加上草，要有風吹過飄動的感覺」→ 新增 `Grass.ts`：70,000 根草葉（觸控裝置 24,000）InstancedMesh、onBeforeCompile 在 MeshStandardMaterial 插入風的位移（陣風波浪 + 細微抖動 + 車子 2.4 公尺內推倒）；作品圓台與跳台不長草
  - 雙面草葉背面全黑 → fragment 中 `normal *= faceDirection` 抵消雙面材質的法線翻轉
  - 驗證：車子靜止時 0.5 秒內草地區域約 9.8% 像素變化（風在動）；M2 60 FPS
