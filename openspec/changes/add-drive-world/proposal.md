# Proposal

## 變更名稱

add-drive-world — 駕駛探索作品集（參考 bruno-simon.com 的玩法）

## 背景

使用者希望建立類似 https://bruno-simon.com/ 的範例：開著小車在 3D 世界中探索、撞倒物件、開到區域進入作品。僅參考玩法，所有模型、素材、程式皆原創（不使用該站資產）。

## 目標

建立 `drive.html`：玩具風小島，駕駛小車探索，6 個作品區域連到本專案其他範例，作為整個專案的互動入口。

## 範圍

- 包含：
  - 物理：cannon-es（RaycastVehicle 車輛、剛體碰撞、休眠）
  - 車：玩具車造型、引擎 / 轉向 / 煞車 / 加速 / 跳躍 / 喇叭 / 重置（翻車自動提示）
  - 世界：小島（草地、沙灘、海）、可撞倒的「THREE LAB」方塊大字、保齡球瓶、木箱金字塔、跳台、樹、邊界
  - 作品區域 ×6：地面發光圓台 + 名稱，車停在範圍內顯示卡片，Enter / 按鈕進入
  - 鏡頭：跟車、固定斜角、滑鼠拖曳旋轉、滾輪縮放
  - 效果：輪胎揚塵、陰影跟著車移動
  - 聲音：引擎聲（隨速度變調）、喇叭（Web Audio 合成）
  - 操作：鍵盤（WASD / 方向鍵、Shift、Ctrl / B、Space、Enter、R、H、L）、觸控（拖曳方向駕駛、點車跳躍、按鈕）
  - 開始畫面（點擊後才開聲音，符合瀏覽器自動播放限制）
- 不包含：成就、排行榜、留言板、地圖、多人

## 影響面

- 新增 `drive.html`、`src/drive/**`；新增依賴 `cannon-es`；`vite.config.ts` 新增頁面

## 風險與對策

- 物理與畫面不同步 → 固定步長 `world.step(1/60, dt, 3)`，每幀把剛體位置複製到 Mesh
- 物體很多時效能 → SAPBroadphase、allowSleep、陰影相機只涵蓋車附近
- 車翻覆卡住 → 偵測朝上向量，2 秒後提示並可按 R 重置

## 驗證方式

- Playwright：鍵盤駕駛位移、轉向、煞車、跳躍、撞倒物件、進入區域卡片與 Enter 導向、重置、觸控、FPS
- 截圖
