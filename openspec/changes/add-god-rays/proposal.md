# Proposal

## 變更名稱

`add-god-rays`：畫面上方的森林光束

## 背景

使用者要求「上方再幫我增加一些光束」，補充說明是「畫面整體上方」、「類似森林那樣的光束」，並要求「不要放射光，全都用左上到右下的光」。

## 目標

- 整個畫面左上角灑下一道道平行、往右下斜的柔和光束，慢慢飄移、呼吸；不受鏡頭轉動、視窗寬窄影響。
- 面板「畫面上方光束（森林光）」可調顏色、亮度、斜度、最亮處、密度、銳利度、延伸距離、速度。

## 範圍

- 新增 `src/world/godRays.ts`；`main.ts` 在每幀最後（前景模糊之後）畫上去、加面板。

## 不在範圍

- 不做真的體積光（不依場景遮擋計算），只是畫面上的疊加光。
