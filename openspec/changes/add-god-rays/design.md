# Design

- 全螢幕四邊形、`AdditiveBlending`、不測不寫深度、`toneMapped: false`，在 `foregroundBlur.render()` 之後畫：只會讓畫面變亮，不會遮住東西。
- 光束方向固定：從「直直往下」往右轉 `angleDegrees`（預設 38°），所有光束平行。
- 橫跨光束的座標 `dot(p, across)` × 密度，兩層 1D 平滑雜訊（粗＋細、各自往不同方向飄）決定哪裡有光；先用 smoothstep 拉開對比再依銳利度取次方（直接取次方會整片太暗，疊在明亮天空上看不出來）。
- 從左上角（`originX`）進來最亮：沿光的方向走越遠越淡（`reach`），橫向也稍微淡一點；整體慢慢呼吸。
- 畫面座標先乘寬高比，斜度不會被視窗比例拉扁。
- 曾先做成「從畫面上方一點放射出去的扇形光」，使用者要求改成平行斜光後改掉；也曾誤做成菠蘿麵包上方的光錐，已還原。
