# Validation

## 結果：通過

- `tsc --noEmit`、`npm run build` 通過；headless 檢查各 mesh 無 NaN、斜撐範圍正確。
- 近拍（正面、左側、木筏特寫）：豬鼻、耳朵（左耳往左上斜出、根部埋進頭）、捲尾、門廊與半截木門、圓窗遮板、吊鈴、芭蕉葉、卡通木筏與欄杆都正確。
- 大小：木筏 ×1.6、樹幹 ×1.6、芭蕉葉 5 片 ×1.4 → 原木數、欄杆柱、門口都跟著調整（`tree-house-resized.png`）。
- 場景與面板：點選 → 「豬豬樹屋 · tree_house_1」發亮；複製 1 → 2、移除 2 → 1；改芭蕉葉片數 → 葉子重建（8316 頂點），豬屋 mesh 是同一個物件（沒有重建）；console 無錯誤。

## 問題與修正

- 豬耳朵一開始是尖刺狀 → 改成圓弧三角形薄片；左耳側面朝鏡頭像一根棍子 → 改成直接指定方向；使用者回報左耳像掉下來 → 改往左上斜出、根部埋深。
- 內耳與外耳正面重疊閃爍（z-fighting）→ 內耳往前移。
- 平面泥巴斑點陷進球面像破洞 → 拿掉，改用 shader 斑駁。
- 門廊後方的粉紅球面從門洞穿出 → 門廊正面移到球面前方。
- 小原木端面出現樹墩的放射裂縫（像時鐘指針）→ 只有大切面才畫裂縫。
- 芭蕉葉背光面發黑 → 加透光自發光、葉面朝前上方；葉子太細像羽毛 → 加寬。

## 第二輪（使用者回報）

- 「門口處需要有梯子、背後需要有一條繩子」：
  - 梯子：兩根原木側桿從木筏門口斜靠到地面，橫木階數跟著支架高度（`supportTop / 0.11`），寬度跟著門口；用同一套卡通木頭 shader。
  - 麻繩：綁在後面扶手上（一圈麻繩環），微微飄著垂到地面、尾端在地上捲一圈，中間 3 個繩結。
- 近拍正面、背面、支架 ×2.2：梯子變長、階數變多，繩子垂到地面；`tsc`、build 通過、console 無錯誤（`tree-house-back.png`、`tree-house-tall.png`）。

## 第三輪（使用者回報）

- 「芭蕉葉要像檸檬片那樣可以任意編輯」→ 每片葉子改成獨立 mesh／獨立材質，設定存在樹屋佈局的 `leaves` 陣列（方位、高度、往外倒、左右轉、葉面自轉、長、寬、下垂、顏色）。
  - 面板「芭蕉葉（豬豬樹屋）」：點選葉子 → 只有那片發亮、顯示該片設定；複製（同一棟、往旁邊轉 25°）、移除、印出全部佈局。
  - 拖曳：capture 階段攔截 pointer 事件（不會拖到整棟樹屋、也不會轉動畫面）；射線換到隱形身體代理的座標（單位球），打到用交點、沒打到用最近點 → 換算方位／仰角。
  - 每片葉子的細節亂數種子建立時固定，增減別片不影響。複製樹屋時 leaves 深複製。
- 實測：點 leaf_2 → 標題「芭蕉葉 · tree_house_1 / leaf_2」、只有它發亮；拖曳後 100°/42° → 147°/34°，樹屋位置與鏡頭不變；複製 3 → 4、移除 4 → 3；console 無錯誤（`tree-house-leaf-panel.png`）。
