# Proposal

## 變更名稱

`add-tree-house`：綠球上的「豬豬樹屋」：豬造型小屋蓋在樹幹撐起來的卡通木筏上

## 背景

使用者提供一張遊戲美術參考圖（豬頭造型小屋＋院子）。第一版做成「矮樹墩小屋＋院子」後，使用者改要求：
- 使用圖片原本的設計、只保留建築主體（豬造型小屋），下方用樹木支架撐起
- 平台改成方形、木筏感、有欄杆，並且卡通化、可以改大小
- 建築右上方三片大芭蕉葉，改成獨立物件、可以自己設定
- 修正左耳看起來掉下來

## 目標

- 豬屋：圓胖身體、門上方豬鼻子、一垂一翹耳朵、捲尾巴、拱形門廊＋白色半截木門、圓窗＋撐開的圓木板、吊鈴。用本專案的低多邊形風格重做，不使用原圖的標誌與文字。
- 底座：樹幹＋彎樹枝斜撐＋方形木筏＋原木欄杆（正面留門口），卡通木頭 shader（放大不糊）；木筏大小、樹幹粗細、支架高度可調。
- 芭蕉葉：獨立 mesh、獨立設定（顯示、片數、大小、方位、高度、往外倒、攤開角度、下垂、顏色），改它只重建葉子。
- 跟樹墩一樣可拖曳選取、面板調整、複製、移除、印出佈局。

## 範圍

- `src/world/objects/treeHouse.ts`、`treeHouseLayout.ts`
- `treeStump.ts`：匯出 `buildStumpGeometries`；小端面（`aCoord.z < 0.6`）不畫放射裂縫
- `obj.ts`、`main.ts` 接線（面板「豬豬樹屋」＋子資料夾「芭蕉葉」、`TREE_HOUSE_SCENE_EDIT` 開關）
