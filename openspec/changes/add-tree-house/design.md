# Design

## 構成（模型座標：木筏寬約 1.2 × raftSize，+z 是門）

| 部分 | 做法 |
| --- | --- |
| 樹幹 | `buildStumpGeometries`（樹墩幾何）拉高、變細，樹根外張當底座 |
| 斜撐 | 4 根 QuadraticBezier TubeGeometry，補上樹皮 shader 需要的頂點屬性（`asBark`） |
| 木筏 | Lathe 圓角原木（平的端面標成年輪 aKind = 1），甲板原木沿 x、底下 3 根橫木 |
| 欄杆 | 原木柱＋上下兩條扶手＋麻繩圈；正面中間留門口（寬度跟著豬屋大小） |
| 梯子 | 門口兩根斜靠的原木側桿＋橫木（階數跟著支架高度） |
| 麻繩 | 後方扶手垂到地面的 CatmullRom 管子＋繩結＋地上捲一圈 |
| 豬屋身體 | 豬屋零件另外收集成 rig（可在平台上左右／前後移動、旋轉，不重建）；壓扁球體；`surface(方位, 仰角)` 回傳橢球表面上「+z 朝外」的矩陣（法線除以半徑平方） |
| 圓窗 | 垂直擺正的窗框＋水平圓木板遮雨棚（兩根斜撐），位置 -88° 避開耳朵 |
| 門廊 | 拱形挖洞擠出，正面放在球面前方，後半段埋進身體（避免身體從門洞穿出） |
| 耳朵 | 圓弧三角形薄片＋內耳；直接指定「長的方向」與「正面方向」組旋轉矩陣；左耳是右耳的 x 鏡射；前後／厚度／大小可調 |
| 芭蕉葉屋頂 | 預設 6 片大葉子排成 A 字屋頂（前後斜面各 3 片）；整組可繞豬屋身體中心旋轉／前後傾／左右傾、放大、上升下降（leafPivot） |
| 芭蕉葉 | 每片獨立 mesh（程式葉片：彎曲葉脈、V 形折、波浪葉緣、撕裂縫、頂點色漸層）；以葉片中心為操作點（錨點＋離身體距離＋上浮；往外倒、左右轉、自轉、向下旋轉都繞彎曲後的葉片中點）；拖曳相對移動、Shift 上下拖調上浮 |

## 材質

- 卡通木頭 shader（`createCartoonWoodMaterial`）：側面兩色色塊＋兩條描線（雜訊等高線、fwidth 抗鋸齒），端面三圈粗年輪＋髓心＋外圈樹皮＋描邊；無凹凸。樹幹、斜撐、木筏各一個實例（uStretch 不同），共用一支 shader。
- 豬屋：頂點色＋模型座標雜訊的細微斑駁。
- 芭蕉葉：DoubleSide＋一點自發光（透光感，背光面不會黑掉）。

## 重建策略

- 豬屋／底座：樹幹種子、豬屋大小、支架高度、木筏大小、樹幹粗細、顏色改變時才重建。
- 芭蕉葉：自己的 key，只在葉子設定或豬屋重建時重建。
