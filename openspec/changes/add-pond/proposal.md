# Proposal

## 變更名稱

`add-pond`：在綠球上加一個小水潭

## 背景

使用者要求「幫我增加一個小水潭」。

## 目標

- 綠球正面左側的空草地上有一個卡通風格的小水潭：
  - 水面有深淺漸層、會擴散的漣漪、岸邊水花；
  - 岸邊有泥土、石頭、荷葉、小粉花和香蒲。
- 面板「小水潭」可以調整，水潭可以拖曳。
- 小豬會繞過水潭；草叢、小道具不會長在水面上，搬動水潭後會重新撒。

## 範圍

- 新增 `src/world/objects/pond.ts`（程式產生，不是 GLB）。
- `obj.ts`：建立水潭，接上開場動畫、更新、障礙清單和撒草避讓。
- `main.ts`：面板、拖曳、拖完重新撒草。

## 不做

- 不走 Blender 建模：水潭是貼在地面上的一片，重點在水面 shader，不在模型形狀。
- 不做真實的水面反射（render target）：成本高，卡通風格用 shader 漸層加漣漪就夠了。
