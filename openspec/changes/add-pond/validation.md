# Validation

## 結果：通過

- `npx tsc --noEmit`、`npm run build` 通過。
- 瀏覽器（headless Chromium）：
  - 水潭出現在預設位置。
  - 水面中央深藍、靠岸淺色，有白色漣漪和岸邊水花；荷葉、小花、石頭、香蒲都正常。
  - 草叢撒完之後，水面和岸邊石頭範圍內沒有草、小石頭或小樹叢，其他地方正常（1000 叢）。
  - console 沒有錯誤。
- 截圖：
  - `docs/Engineering Evidence/assets/pond-close.png`
  - `docs/Engineering Evidence/assets/pond-in-scene.png`

## 說明

headless 瀏覽器的開場動畫比較慢，45 秒內有時還沒撒草，看起來像「整顆球沒有草」。這不是 bug：等草撒好再截圖就正常。

## 遮罩重驗（移動水潭不影響佈局）

在瀏覽器裡讀出四種 InstancedMesh 的全部矩陣，前後比對：

| 情境 | 草叢 | 小石頭 | 蘑菇 | 小樹叢 |
|---|---|---|---|---|
| 總數（不變） | 1000 | 45 | 30 | 35 |
| 原位置藏起來 | 32 | 3 | 0 | 1 |
| 水潭搬走後有變動 | 36 | 3 | 0 | 1 |
| 搬回原位後與一開始不同 | 0 | 0 | 0 | 0 |

- 搬走時，只有舊位置長回來的加上新位置藏起來的有變動，其他一千多個完全沒動。
- 搬回原位後和一開始完全一樣。
- 水面截圖乾淨，console 沒有錯誤。
