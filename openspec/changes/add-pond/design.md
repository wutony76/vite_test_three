# Design

## 1. 為什麼水面比草地高

綠球是實心的，挖到球面以下的東西會被綠球擋住，所以水面「挖不下去」。

做法：
- 水面比地表高 0.0016，岸邊泥土內圈再高一點（0.0026），把水面邊緣蓋住；
- 外面再圍一圈石頭，看起來就像凹下去的水潭；
- 用 `polygonOffset` 避免和綠球 z-fighting。

## 2. 幾何（`pond.ts`）

- **輪廓**：`shoreRadius(θ)` 是圓疊上 2、3、5 次的低頻正弦，形狀不規則。
- **水面**：極座標網格，7 圈 × 56 段。每個頂點用 `groundY(x,z)` 貼到球面，不然邊緣會翹起來。
  - 自訂 attribute `aPond`（單位座標）和 `aEdge`（中心 0 到岸邊 1），給 shader 使用。
- **岸邊泥土**：4 圈，vertex color 帶 alpha，外圈完全透明，和綠球草地的顏色自然接起來。
- **石頭**：一個 InstancedMesh，16 顆，大小、顏色、角度隨機。香蒲那一側留空。
- **荷葉**：缺一角的 CircleGeometry，其中一片上有五瓣小粉花，會慢慢轉。
- **香蒲**：細長葉子加咖啡色的穗，支點在根部，隨風擺。
- 大小、下沉、香蒲開關改變時才重建幾何（`builtKey`）；顏色和漣漪只更新 uniform。

## 3. 水面 shader

MeshStandardMaterial 加 `onBeforeCompile`：
- **深淺**：`mix(deep, shallow, smoothstep(0.45, 1.0, aEdge))`。
- **漣漪**：兩個中心錯開、往外擴散的細亮線，離中心越遠越淡。
- **岸邊水花**：`smoothstep(0.86, 1.0, aEdge)` 混白色。
- **其他**：roughness 0.32、envMapIntensity 0.35，加一點自發光。
  - 原本用 roughness 0.12，斜看時環境反射會把整片水洗成白灰色。

## 4. 草叢避讓：用遮罩，不用障礙

使用者發現的問題：移動水潭會讓整顆球的小物件佈局亂掉。

- **原因**：`groundDetail` 撒點用固定種子加拒絕取樣。只要水潭算在 `getObstacles` 裡，水潭一動，某些點就從合格變成不合格（或反過來），後面整串亂數全部錯開，整顆球的草、石頭、蘑菇、樹叢都會重排。
- **做法**：
  - 水潭不放進 `getObstacles`，改放進新增的 `getMasks`。
  - 撒點完全不管水潭，撒完後記下每個 instance 的原始矩陣；`applyMasks()` 把落在遮罩範圍內的縮放歸零，其他還原成原始矩陣。
  - 水潭移動、改大小或開關時，只呼叫 `groundDetail.refreshMasks()`，不重撒。
- **範圍**：`atan(size × 1.45 / R)`，涵蓋岸邊石頭。直接用設定計算，不量模型：第一次撒草時水潭還在開場動畫前，縮放是 0。
- **結果**：綠球的佈局和加水潭之前完全一樣，只是水潭範圍內的被藏起來。
- **小豬**：仍然把水潭當障礙，會繞著走。

## 5. 預設值

使用者在面板上調好後提供：

| 項目 | 值 |
|---|---|
| 離頂端 | 16° |
| 方位 | 171° |
| 自身旋轉 | −72° |
| 半徑 | 0.095 |
| 下沉 | 0 |
| 深處顏色 | `#2F8FBF` |
| 岸邊顏色 | `#8FE3E6` |
| 漣漪 | 1 |
| 荷葉 | 開 |
| 香蒲 | 開 |

位置在龍兔的家背面，是溜滑梯（`add-main-hall-slide`）的終點。
