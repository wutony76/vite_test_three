# Proposal

## 變更名稱

`add-ketchup-riders` — 番茄醬上的食物與鯊魚改善

## 背景

使用者問番茄醬裡的食物和鯊魚有什麼要改，我提出食物 4 項、鯊魚 4 項，使用者要求全部一起處理。

更正：建議時說鯊魚「90 秒都在綠球背面」，那是無頭瀏覽器的測量失真。番茄醬每幀的時間差上限是 0.1 秒，而無頭模式每秒只有一兩幀，鯊魚在測試裡被放慢了約 5 倍。照程式數值，正常 60 fps 下鯊魚約每 9 秒繞一圈。所以鯊魚第 1 項改成「放大鰭」，不改速度。

## 目標

### 食物

1. **放大並提高對比**：
   - 雞腿 0.065 → 0.095、薯條 0.027 → 0.045。
   - 雞腿表皮改成亮一點的金黃烤色。
   - 所有食物加邊緣亮光。
2. **增加數量**：預設 11 → 20 塊，前景比較常看得到。
3. **增加種類**：香菇、檸檬片，沿用綠球上已有的模型。
4. **泡在醬裡的感覺**：每塊食物底部加一圈扁平的沾醬圈。

### 鯊魚

1. 鰭放大 1.3 倍。
2. 鰭的形狀改成前緣外凸、鰭尖後勾，邊緣有倒角；顏色改成深藍灰 `#56708c`。
3. 兩側水波從亮粉色改成奶油白，水波貼圖中的淡藍色筆畫改成暖奶油色。
4. 偶爾躍出醬面畫一道弧線，落下時醬面起兩圈漣漪。

所有項目都能在面板調整。
