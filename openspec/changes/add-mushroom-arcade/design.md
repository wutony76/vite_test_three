# Design

## 1. 簡化方向（參考第二張香菇屋）

**保留的設計感**：
- 圓潤的奶油色牆（俯看是超橢圓、側看中段微微鼓起）；
- 木腰帶加青苔邊、青色霓虹燈條；
- 綠色八角拱門、像素框窗（窗內用發光 decal 表現店內）；
- 霓虹招牌、屋頂一叢白點發光紫香菇、兩朵垂掛小香菇串的大紫香菇、右側街機台、底座小紫菇。

**拿掉的部分**：屋頂樓梯、水管和配電箱、側門和浮雕、屋頂雜物。店內人物和牆上的像素圖示都用 decal 表現，不做成幾何。

## 2. 零件重點（`mushroom_arcade.py`）

- **`ma_block`**：每個高度一圈超橢圓，loft 成 1 個封閉島。`ROUND_P = 6`。
  - 一開始用 4，但窗內 decal 是平的，靠轉角的窗在 4 時畫面會超出彎曲的窗框。
- **貼牆零件（門、窗）**：params 帶上所屬屋身的 `wall_bounds`，用同一個公式 `_wall_front` 算牆面。
  - 玻璃和門內面板用 `_conform_slab`：每個高度一圈切面，前緣逐點貼牆。
  - 框、霓虹管用 `_on_wall` 逐點貼牆。
  - 一開始用平的面板，在弧形牆上邊緣凸出一塊厚板。
- **招牌**：掛上去的平板，前面平；背面伸到牆面最內側再往裡，邊緣不露縫。
- **發光斑點香菇**：白色斑點是把傘面上一部分面換成 `spot_white` 材質，不加幾何；三朵 = 3 個島，不超過 decoration 上限 8。
- **大香菇吊飾**：「繩 → 珠 → 倒掛小香菇 → 尾珠」做成一個旋轉體，每串只算 1 個島。

## 3. decal

- 用程式畫（`make_mushroom_arcade_decals.py`）：霓虹字是光暈、燈管、白芯三層疊起來；窗內是紫光漸層、格子地板、遊戲機剪影。
- 圖片長寬比和 plan 的 rect 一致，rect 都落在玻璃、面板、字面裡面（decal 取 rect 內最外側的表面深度，壓到框會浮起來）。
- 街機螢幕是斜的，貼 decal 會變成垂直板浮在前面，所以改用發光材質。

## 4. 預算處理

- 三角面 15774／16000：貼牆面板的網格降到門 8×8、窗 8×6。
- 貼圖 GPU 從 28 MB 降到預算內：木板和灰泥都改成 prop 等級（512），不調高預算。

## 5. 網頁：取代 GameHall

- `GAME_HALL_MODEL_URL` 換成 `mushroom_arcade.glb`。
- 長方體比例改成模型的比例（寬 9.1、高 10.2、深 6.6 → 1.25 : 1.40 : 0.91），因為 `fitIntoHouseBox` 是三邊都不超出的等比縮放。
- 自轉：在頁面上掃 −180～180°，量模型正面（glTF +Z）和鏡頭方向的夾角，90° 最正面。
- 原本模型的值寫在註解裡：`gameHall.glb`、spinDegrees 99、height 0.95、depth 1.15。
- **`gameHallLights`**：只認舊模型裡特定名稱的零件，新模型沒有這些名稱，不會出錯，只是沒作用。
- **decal 發光**：沿用 GameHall 原本的 `lightUpGlowDecals`。
- **荷包蛋**：沒有掛在 GameHall 上，不受影響。

## 6. 配色調整（使用者回饋）

1. **第一次調色**：使用者提供第三張參考（霓虹電子遊樂中心，`tools/img/mushroom_arcade_neon_palette.png`），改成深靛藍牆、紫色邊框、洋紅霓虹、水泥灰底座。
2. **使用者回饋**：「同色系有點太多」，而且屋頂要保留原本的木頭色。
3. **重配**：

| 部位 | 顏色 |
|---|---|
| 牆、右側街機台 | 偏藍的深藍 `#2F3A8F` |
| 屋頂、樓層腰帶、招牌木板 | 原本的木頭色 `#8A5A3C` |
| 門框、招牌框 | 金黃 `#F2C14E` |
| 腰帶下緣 | 粉紅 `#FF6FB5` |
| 霓虹燈條 | 洋紅 |
| 像素窗框 | 青 |
| 大香菇 | 珊瑚紅 `#E2574C`，傘緣 `#A33A32`，白柄 |
| 屋頂發光小香菇 | 青 `#3FE0E8` |
| 底座 | 水泥灰 |

- 二樓圖示窗的 decal 底色改成深藍。
- 原本的奶油色配色記在 memory 的 `project-gamehall-palette`，可以隨時換回。

## 7. 半弧屋頂、屋頂小菇、一樓牆色（使用者回饋）

**半弧屋頂與閣樓**：重用 Happy Fat 的 `em_arc_shell`（閣樓牆，深藍）和 `em_arc_roof`（半弧屋頂，木頭色加深木色邊），只換參數：

| 參數 | 值 |
|---|---|
| left_x | −3.1 |
| right_x | 2.4 |
| eave_z | 7.6 |
| top_z | 9.6 |
| overhang | 0.35 |
| thickness | 0.4 |
| depth | 1.5 |

- 閣樓比二樓窄，前面留一條露台。「GAME START!」和像素外星人招牌立在露台上。
- **屋頂小菇**：照原設計，發光小香菇叢和大香菇種在屋頂上。
  - `ma_spotted_cluster`、`ma_big_mushroom` 新增 `params.on_roof`（同一組屋頂參數）。
  - 每朵底部照屋頂外側曲線算高度（往下埋 0.06），高度改以「屋頂表面到 bounds 頂」計算；否則底部被抬高，香菇會長出 bounds，重建時 bounds 一直變。
- **一樓牆色**：一樓改用新材質 `wall_ground`，深青綠 `#1E6F78`，跟二樓深藍區分，和青色窗框同色調。
- **網頁**：模型變高（約 12.3），GameHall 長方體高度 1.4 → 1.70；不改的話整棟會被高度卡住、縮小一圈。
- **驗證**：
  - 22 個 Object、17286 個三角面，預算改為 18000。
  - `test_shapes` 27 passed，`threejs_plan_check` ALL PASS。
  - 瀏覽器沒有錯誤，`tsc` 和 build 通過。

## 8. 改成兩層樓（使用者要求：「三樓的造型放到二樓，這個物件是二樓的建築」）

- 拿掉原本方塊狀的二樓（ma_block）與它的木腰帶 `roof_band`；原本疊在上面的弧形閣樓（em_arc_shell，Happy Fat 同款）直接當二樓 `uf_shell`，坐在一樓木腰帶上（z 3.85），寬深沿用原二樓（x −3.3～2.7、depth 2.2），頂部接半弧屋頂（eave 6.4、top 8.6）。
- 貼牆零件支援弧形牆：`mushroom_arcade.py` 的 `_wall` 讀 `arc_wall`（屋頂參數＋牆底 z0），`_wall_front` 改用 earth_mamas 的 `shell_half_depth` 算牆面 y，二樓兩扇窗逐點貼弧形牆。
- 沒有屋頂露台了：「GAME START!」與像素外星人改掛在二樓牆面上方（decal rect 跟著移）；霓虹只留一樓腰帶那一圈。
- 屋頂香菇照新屋頂曲線 `on_roof` 重算高度；模型高 11.2，網頁 GameHall 長方體比例改 1.25 : 1.54 : 0.91。
- 驗證：build exit 0（20 個 Object、15412 tris、43 primitive）、test_shapes 27/27、threejs_plan_check ALL PASS、網頁場景無 console error。
- 追加（使用者要求「二樓高度跟一樓一樣」）：屋簷 6.4→5.4、最高點 8.6→7.6，二樓牆平均高約 3.3（一樓 3.25）。二樓重新排：左窗＋像素外星人＋大窗一排，「GAME START!」在左窗上方；屋頂香菇跟著降；模型高 10.2，網頁比例 1.25 : 1.40 : 0.91。
- 追加（使用者要求「二樓牆壁顏色改 499883」）：二樓用新材質 `wall_upper` #499883（palette #36746A / #499883 / #64B5A0）；`wall_cream` 留給街機台維持深藍。多一張牆面貼圖，`max_gpu_texture_mb` 24→26。
